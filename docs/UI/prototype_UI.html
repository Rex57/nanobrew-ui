Nanobrew UI prototype

The approved mockups of the Nanobrew UI 1.0.0 design pass: each screen in light and dark. The Updates rows (and the Installed update and pin marks) are sample data; the other figures were read from a real nanobrew 0.1.214. The "Recently upgraded" list on the Updates screens is a future idea: it is not in 1.0.0 (see the README's "Future ideas").

Reinstall Firefox?

nb can't upgrade Firefox in place, because it comes as a disk image. Reinstall removes Firefox 144.0 first, then installs 145.0.1.

If the install fails, for example with no network, Firefox stays removed until you install it again. Your settings in ~/Library stay.

Quit Firefox before you continue.
